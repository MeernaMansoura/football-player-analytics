                                                           English Premier League Data Analysis & Valuation Project

                          1 . نظرة عامة على المشروع (Project Overview)
*يهدف هذا المشروع إلى تحليل أداء لاعبي كرة القدم في الدوري
*تم دمج بيانات متعددة (معلومات اللاعبين، الإحصائيات، والرواتب)، وكشف الرؤى الخفية حول كفاءة اللاعبين والفرق بين الأجور والأداء الفعلي.

                          2. الأدوات المستخدمة (Tech Stack)
**Python (Pandas, Matplotlib, Seaborn):** لتنظيف البيانات، الدمج، التحليل الإحصائي، وتوليد الرسوم البيانية.
**Jupyter Notebook / Python Scripts:** لتنفيذ الكود خطوة بخطوة.
 
                          3 . خطوات العمل والتحليل (Workflow)
1. تنظيف ودمج البيانات:- معالجة القيم الفارغة (مثل Clean Sheets لحراس المرمى) ودمج جداول المعلومات، الإحصائيات، والرواتب بدقة مع تجنب تكرار الأعمدة.
2. تحليل الهدافين وصانعي الألعاب: -استخراج النجوم الأكثر تأثراً هجومياً (أهداف وتمريرات حاسمة).
3. تحليل الأجور مقابل الأداء: -دراسة معامل الارتباط (`Correlation = 0.39`) واكتشاف أن الرواتب الأعلى لا تذهب بالضرورة لمن يسجل أكثر فقط، بل للمساهمات الشاملة.
4. البحث عن "الكنوز المخفية" (Value for Money): حساب تكلفة المساهمة الواحدة (`Cost Per Contribution`) للتعرف على الصفقات الاقتصادية الرابحة.
